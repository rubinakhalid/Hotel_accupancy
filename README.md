# Hotel Occupancy Project

## Overview
This C++ program calculates the hotel occupancy statistics based on user input.
The program asks:
- How many floors the hotel has  
- How many rooms are on each floor  
- How many of those rooms are occupied  

It also includes complete *input validation* and skips the *13th floor*, which is a common hotel tradition.

After collecting data from all floors, the program displays:
- Total rooms
- Total occupied rooms
- Total unoccupied rooms
- Occupancy rate (percentage)

---

##  Features
- Input validation for all user entries  
- Skips floor 13  
- Uses loops and conditionals  
- Calculates occupancy rate accurately  
- Clear and organized console output
